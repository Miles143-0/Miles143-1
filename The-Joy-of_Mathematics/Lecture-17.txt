The Joy of Infinite series:	// .999999=1 //
				Infinite series is the result of adding an unlimited number of terms together according to a pattern.

			//	Ex: Consider 1+2+3+4+5+... // the dots mean that the pattern continues forever //

				NOTES:	// sum(n=1 to infinity) a_n, or
						sum(n=1 to infinity), 1/n or 
							sum(n=1 to infinity) 1/(2^n), or 
								∑n=¹∞ aₙ //
									NOTES: //	∑= add everything,
											n=1 =start at 1
											∞= continue forever
											n= the term being added //

			//	Ex-2:	1+1/2+1/4+1/8+1/16+1/32+1/64+1/128+1/256+...
					0=0, 1=0.5, 2=0.75, 3=0.875, 4=0.9375, 5=0.96875, 6=0.984375, 7=0.9921875, 8=0.99609375, 9=0.998046875
					S(n)=1/2+1/4+...1/2ⁿ
					S(n)=1-(1/2ⁿ)
					lim(n→∞) S(n)=1	
				//	Conclusion: As the number of terms increases, the running total appraoches 1 but never reaches 1 in any 
					finite number of terms.	

					This is called CONVERGENCE. //
