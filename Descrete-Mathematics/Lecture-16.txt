							Walk:	A sequence of vertices connected by edge; vertices &  edge may repeat.
							Trail:	A walk that never repeats an edge.
							Path:	A walk that never reoeats a vertex.
							Cycle:	A path that starts and ends at the same vertex, without repeating any other vertex.

							Ex:	1. Walk: a walk can repeat vertices and edges 3→1→7→4→5→7→9→1→2→3.
								2. Path: a path does not repeat vertices 3→1→7→4→5→9→2 // 7 distinct numbers //
								3. Trail: a trail does not repeat edges but can revisit vertices 3→1→7→4→5→9
								4. Cycle: a cycle starts and ends at the same vertex  without repeating other vertices. If we define the graph with edges 
									connecting 3-1,1-7,7-3 then 3→1→7→3 // a closed trail, and the graph is connected  if for all vertices x and y, there is a path from x to y. //.
