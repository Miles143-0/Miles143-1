Modular Arithmetic-The Math of Remainders:	Introducing Modular Mathematics; We say that a and b are congruent modulo m, or a≡b(mod m
						if a and b differ by a multiple of m. We will learn how conguence relation behaves a lot like
						equality.


						I.	A. Modular Arithmetic is mathematics of remainders, and was invented by Carl Friedrich Gauss
							B. Definition: m>0, we say that a≡b(mod m) if m|(a-b)
								1. a is congruent to b mod m if m divides a-b. The number m is called the modulus.
								2. Equivalently, a and b differ by a multiple of m.
								3. Equivalently, a=b+mj for some integer j =, or a and b hace the same remainder 
									when divided by m.
								4. Equivalently, a mod m=b mod m
								5. Ex: 10≡2(mod 4), a=10, b=2, Definition: m=4 a≡b(mod m) if m|(a−b). <----forget for now.
									compute the difference: 10-2=8,
									since 4|8, we conclude that 10≡2(mod 4)
									Equivalent definitions of conguence:
														1. 4|(10-2),
														2. 10 and 2 differ by a multiple of 4.
														3. 10=2+4(2)
														4. 10 and 2 have the same remainder when divided by 4.

							C.	1. standard clock is working mod 12.
								2. A standard calendar is working mod 7, since the day of the week repeats ever seven days.
							D. The congruence relation acts a lot like the equality relation.

						II.	Congruences resemble equality and are central to modular arithmetic.
							A.	1. Congruences can be added: a≡b(mod m) and c≡d(mod m), then a+c≡b+d(mod m)
								2. Then m divides a-b abd b-c and therefore divides their sum.
								3. Thus m divides (a-b)+(c-d)=(a+c)-(b+d)
								4. Thus a+c≡b+d(mod m).
									Ex:	Suppose we have two sets of points (10, 2) and (11, 4),  and we'd like to add them.
										For the congruence rule, we need to compare the differences:
											1.	10−2=8
												11−4=7<----first we need to compare the differences.
											2.	We need to find the common divisor, the only positive number that 
												divides both 8 and 7 is 1,
												so,
													10≡2(mod 1)
													and
													11≡4(mod 1)
											3. mod 1 is not very useful because every number has a remainder of 0.
							B. Congruences can be multiplied: If a≡b(mod m) and c≡d(mod m), then ac≡bd(mod m)
								1. Proof: We are given that a=b+jm for some integer j and c=d+km for some integer k
								2. Thus ac=(b+jm)(d+km)=bd+bkm+jmd+jkm²=bd+m(bk+jd+jkm)
								3. Thus ac≡bd(mod m)<-----NOTE: If two numbers can be replaced by numbers with the same remainder,
												multiplying those replacements will still give the same remainder.
//											Ex:	suppose we have (10,2) and (11,4),
											1.	suppose we have (3,1) and (5,3)
											2. 	compare the differences so,	3−1=2
																5−3=2.
																The differences are both 2, so we can use: m=2
																This means:	3≡1(mod 2)
																		5≡3(mod 2).<----when multiplying, do both first numbers,
																				then both second numbers. 
											3.	Multiply:	3·5=15,
														1·3=3
											4.	Check:		15÷2 leaves a remainder of 1
														3÷2 leaves a remainder of 1<-----The remainders match!
											5. 	Final:		3≡1(mod 2)
														5≡3(mod 2)
														therefore:
															3·5≡1·3(mod 2)
							C. The Power Theorem:	if a≡b(mod m),
										then aⁿ≡bⁿ(mod m) <-----If two numbers have the same remainder when divided by m, then raising both numbers to the same power 
													keeps them congruent.
						III.	Casting our 9's:	Checking the answers of big arithmetic problems by summing up the digits of your answer
							A. Ex:	// S(4688)=26<-----4+6+8+8=26 //
							B. Ex: // 4688≡26≡8(mod 9)<-----4+6+8+8=26, 2+6=8 S(4688)=26, so 26, which is S(26) therefore, 	S(26) becuase 2+6=8 (mod 9)
							D. Casting out 11's <-----Ex: // 10 1-0=1, 10≡1(mod 11)<-----with a remainder of 1
											11 1-1=0, 11≡0(mod 11)<-----with a remainder of 0 //
						IV.	Every book has an ISBN, that number is coded using mod-11 arithmetic
							A. The ISBN is a 10-digit number a-bcdef-ghi-j satisfing the following:	// 10a+9b+8c+7d+6e+5f+4g+3h+2i+j+0(mod 11) //
							B. The last digit j is called a check digit, which is used to ensure that the total sum is 0 (mod 11). if j needs to be
								10, then it is coded with symbol X.
						V.	The cancelation theorem: 	If ax≡by(mod m), and if gcd(a,m)=1, Then: x≡y(mod m)
											Ex:	10a≡10b(mod 3)
											check:	gcd(10,3)=1
									since gcd=1 cancel 10:	a≡b(mod 3).
